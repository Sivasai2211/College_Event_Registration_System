# College Event Registration System

A beginner-friendly FSD-II full-stack project using HTML, CSS, JavaScript, Node.js and Express.

## Requirements
- Node.js installed
- VS Code

## Run the project
1. Open this folder in VS Code.
2. Open Terminal.
3. Run `npm install` (only the first time).
4. Run `npm start`.
5. Open `http://localhost:3000` in your browser.

## GitHub commands
Run these commands from the project folder:

```bash
git init
git add .
git commit -m "College Event Registration System"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/College_Event_Registration_System.git
git push -u origin main
```

In the lab exam, clone your repository:

```bash
git clone https://github.com/YOUR-USERNAME/College_Event_Registration_System.git
cd College_Event_Registration_System
npm install
npm start
```

If the repository is already cloned, use:

```bash
git pull origin main
npm install
npm start
```

## Main files to study
- `public/app.js` — frontend logic
- `server.js` — backend logic
- `public/index.html` — page structure
- `public/style.css` — design

Registrations are stored in `data/registrations.json`.
